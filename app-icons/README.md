# Icone app SNAKEcheck

10 concept di icona (`logo-01.svg` … `logo-10.svg`, viewBox 512×512, fondo pieno, simbolo nella zona sicura r=205 px).

- Apri `preview.html` nel browser (doppio clic): scale 256/128/48/24/16 px, sfondo chiaro/scuro, maschere quadrata/arrotondata/squircle/cerchio, 8 luoghi d'uso e le schede di ogni logo. Nessuna risorsa esterna.
- `anteprime/`: immagini della galleria.
- `src/genera-loghi.py` rigenera gli SVG e `preview.html` (`python3 app-icons/src/genera-loghi.py`).
